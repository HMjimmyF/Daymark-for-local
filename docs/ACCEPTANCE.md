## 已测试的数据行为

- SQLite 数据库迁移版本写入与持久化
- 任务创建、编辑、完成、重新打开与软删除
- 一级子任务约束
- 本地“今天”和“未来 7 天”边界
- 一次性与重复提醒的提醒时间都进入“今天”和“未来 7 天”范围
- 收集箱收纳未设提醒时间、或未分类的任务，两者都设置后离开收集箱
- 分类删除时将任务移入收集箱
- 备份创建、完整性检查与恢复
- 提醒去重和已完成任务不提醒
- 提醒送达后写入“已提醒”，与完成状态、逾期判断互不影响
- 修改提醒时间会清除“已提醒”并重新进入待提醒队列
- 每分钟、每小时循环推进以及重复截止时间到达后停止循环
- JSON/CSV UTF-8、逗号、引号和换行转义
- 损坏数据库文件被拒绝

- 在未安装 Node.js 的干净 Windows 用户环境解压 ZIP 并启动

- 托盘菜单、关闭到托盘和全局快捷键在目标机器上的冲突情况
- 800×560 最小窗口尺寸及高 DPI 显示
