# 品牌图标资源

图标来自「日序 Daymark」品牌展示板，以日出、地平线和远山为核心元素。所有版本使用同一组品牌色：

- 日出橙：`#FF9F43`
- 晨光米：`#FFE7C2`
- 远山灰：`#8FA2B8`
- 深空蓝：`#1F2937`
- 背景白：`#F7F7F8`

| 文件                   | 用途                           |
| ---------------------- | ------------------------------ |
| `brand-icon.svg`       | 主图标，用于界面品牌标识       |
| `brand-icon-dark.svg`  | 深色背景版本                   |
| `brand-icon-mono.svg`  | 单色版本                       |
| `brand-icon-small.svg` | 小尺寸简化版本                 |
| `app-icon.png`         | Windows 应用主图标             |
| `app-icon.ico`         | Windows 可执行文件多分辨率图标 |
| `tray-icon.png`        | 系统托盘简化图标               |

运行 `yarn icons` 可重新生成 PNG、托盘图标和包含 16–256 像素多分辨率条目的 ICO。
